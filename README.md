# ATM Management System — Python OOP Mini Project

A console-based ATM simulation built with Python and object-oriented programming.

## Features
- PIN authentication with three attempts
- Deposit, withdrawal, and balance inquiry
- PIN change with a demo OTP
- Transaction history
- Amount validation and error handling
- Masked account number

## OOP concepts
Classes and objects, encapsulation, abstraction, composition, constructors, properties,
class attributes, and exception handling.

## Run
```bash
python ATM.py
```
On Linux, you may use `python3 ATM.py`.

Demo PIN: `1234`  
Opening balance: ₹1000

This is an educational demo only. It uses dummy credentials, prints the OTP to the
console, and stores data only in memory. Do not use real banking details.
